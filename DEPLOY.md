# Выкладка

Сайт статический: результат сборки — папка `dist` с html, css внутри html, шрифтами и
картинками. Никакого сервера, PHP и базы ему не нужно.

## Что нужно купить

**Ничего больше покупать не нужно.** Домен `masterravshan.uz` куплен, хостинг не требуется:
Cloudflare Pages бесплатен, разрешает коммерческое использование, даёт безлимитный трафик
и автоматический SSL.

Vercel из первоначального плана не подходит: его бесплатный Hobby-план запрещает
коммерческие проекты, включая случай «вам заплатили за создание сайта».

## Порядок

### 1. Домен — сделано

`masterravshan.uz` куплен. Единственное, что нужно проверить в панели регистратора, —
что там можно **сменить NS-серверы**: без этого не подключить Cloudflare.

### 2. Cloudflare

1. Завести аккаунт на cloudflare.com.
2. **Add a site** → `masterravshan.uz` → план **Free**.
3. Cloudflare покажет два своих NS-сервера. Прописать их в панели регистратора вместо
   тех, что стоят по умолчанию.
4. Подождать, пока Cloudflare увидит делегирование. Обычно это часы, иногда до суток.

### 3. Pages

**Вариант через гит (рекомендуется).** Положить проект в репозиторий, дальше
Workers & Pages → Create → Pages → Connect to Git и указать:

| Поле | Значение |
|---|---|
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node version | 22 или новее |

Дальше каждый `git push` пересобирает сайт сам.

**Вариант без гита.** Собрать локально и загрузить папку:

```bash
npm run build
```

Workers & Pages → Create → Pages → Upload assets, перетащить содержимое `dist`.
Так же придётся делать при каждом изменении.

### 4. Домен к Pages

В проекте Pages → Custom domains → Set up a domain → `masterravshan.uz`.
Cloudflare сам пропишет запись и выпустит сертификат. Добавить заодно `www` с
редиректом на основной домен.

### 5. Проверить после выкладки

```bash
npm run verify
```

И вручную, уже на живом домене:

- открыть `https://masterravshan.uz/` с телефона — кнопка «Позвонить» должна быть внизу
  экрана сразу, без прокрутки;
- нажать её и убедиться, что телефон набирает `+998 90 904 50 10`;
- кинуть ссылку самому себе в Telegram — должна показаться карточка с превью;
- открыть `https://masterravshan.uz/robots.txt` и `sitemap-index.xml`;
- зайти на несуществующий адрес и убедиться, что 404-я осмысленная.

### 6. Google Search Console

Добавить сайт, подтвердить владение (Cloudflare делает это в один клик через DNS),
отправить `https://masterravshan.uz/sitemap-index.xml`.

## Обновления

| Что меняется | Что делать |
|---|---|
| Телефон, Telegram, график, зона выезда | правка `src/data/business.ts`, затем `npm run verify` |
| Сезон: май → `'summer'`, ноябрь → `'winter'` | одна строка в `business.ts`, затем `npm run verify` |
| Появилась страница услуги | `status: 'live'` в `business.ts` — карточки и меню подхватят сами |
| Тексты страниц | правка в `src/pages/`, затем `npm run verify` |

`npm run verify` всегда заканчивается боевой сборкой, так что в `dist` после него лежит
именно то, что можно выкладывать.

## Если понадобится TAS-IX

Ближайшая точка Cloudflare — Алматы, то есть для узбекских посетителей сайт идёт
внешним трафиком. При весе страницы 55 КБ это не заметно, но если замер с ташкентского
подключения покажет плохой TTFB, переезд на локальный хостинг (например, Airnet)
занимает десять минут: собрать `npm run build` и скопировать содержимое `dist`
в `public_html`. Ничего в коде менять не нужно.
